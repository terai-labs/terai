Customize how terai works via the `terai.config.ts` file in your project.

```tsx
import { defineConfig } from '@terai/dev'

export default defineConfig({
  // your configuration options here...
})
```

## File system options

### include

- **Type**: `string[]`
- **Default**: `[]`

List of files glob to to look for your locale declarations.

```json
{
  "include": ["./src/**/*.{js,jsx,ts,tsx}"]
}
```

### exclude

- **Type**: `string[]`
- **Default**: `[]`

List of files glob to ignore.

```json
{
  "exclude": []
}
```

### outDir

- **Type**: `string`
- **Default**: `"./locale-system"`

The output directory for your locale system.

```json
{
  "outDir": "./locale-system"
}
```

## Locale options

### projectLocale

- **Type**: `string`
- **Default**: `""`

The base locale used in your project messages

```json
{
  "projectLocale": "en"
}
```

### outLocales

- **Type**: `string[]`
- **Default**: `[]`

The aditional locales you want to support

```json
{
  "outLocales": ["es", "it"]
}
```

### translator

- **Type**:
  `({ dictionary, locale, projectLocale }: { dictionary: Dictionary locale: Locale projectLocale: Locale }) => Promise<Dictionary> `
- **Default**: `undefined`

The translator for your messages

### batchSize

- **Type**: `number`
- **Default**: `undefined` (all untranslated messages in a single call)

Maximum number of messages sent to the translator in a single call. Batches run
concurrently and are saved independently: if one batch fails, the others are
still written to the cache and the locale files, and only the failed messages
are retried on the next `terai translate`.

```json
{
  "batchSize": 20
}
```

## Translate behaviour

- Translations in the locale files win over the cache, so you can fix a
  translation by editing the JSON file directly.
- Only the message ids that were requested are kept from the translator
  response. Missing or empty values are reported and retried on the next run.
- If any locale fails to translate, `terai translate` lists the failed locales
  and exits with code `1`.
